# 🌸 コスメのホンネ (Cosmetic Auditor v2)

> 忖度ゼロで、肌とお財布の味方。明るくて正直なコスメ分析アプリ

成分表を貼り付けるだけで、広告抜きの「ホンネ採点」・コスパ診断・手持ちコスメの相性チェック・
天気連動の肌アドバイスを、**APIキー不要・ログイン不要・完全ローカル**で提供します。

## 主要機能

- 🔍 **成分ホンネ分析** — 成分表示を貼るだけ。約100成分のローカル辞書+ルールエンジンで
  S〜Dランク採点。「注目成分が配合順の後ろすぎ」「植物エキス盛り合わせは飾り」などの辛口コメント付き
- 💰 **コスパ診断** — 価格と容量から円/mLを算出し、カテゴリ相場と比較。
  「推定ブランド料」をハーゲンダッツ換算で可視化🍨
- 👝 **マイポーチ相性チェック** — 手持ちコスメを登録すると、レチノール×ピーリング酸などの
  NG組み合わせ・好相性を自動判定。朝/夜の使い分けも提案(localStorage保存)
- 🌤️ **今日の肌アドバイス** — Open-Meteo(キー不要)の気象データから乾燥・UV・気温に応じたケア提案

## v1からの変更点

| | v1 | v2(現行) |
|---|---|---|
| バックエンド | Supabase + Edge Functions + Gemini | **なし(完全クライアントサイド)** |
| 認証 | Supabase Auth必須 | **不要** |
| APIキー | Gemini / Yahoo / OpenWeather | **不要**(天気はOpen-Meteo) |
| 分析 | LLM呼び出し | **ローカル成分辞書+ルールエンジン** |
| デザイン | 黒基調(zinc-950) | **明るいピンク×クリーム基調** |

## クイックスタート

```bash
npm install
npm run dev   # http://localhost:5173
```

これだけ。環境変数の設定は不要です。

## 技術スタック

- React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui
- Zustand (persist / localStorage)
- React Router v6
- Open-Meteo API (天気・キー不要)
